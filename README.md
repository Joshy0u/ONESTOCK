# ONESTOCK

## Description
ONESTOCK is an advanced inventory management system designed to track, manage, and visualize stock levels efficiently with modern tooling.

## Tech Stack
* **Frontend:** React, Three.js
* **Backend:** FastAPI (Python)
* **Database:** MySQL

---

## Getting Started

### Prerequisites
* Python (Recommended: 3.10+)
* Node.js & npm

### 1. Virtual Environment & Dependencies
Set up the Python virtual environment and install the required backend dependencies:

```bash
# Create the virtual environment
python -m venv venv

# Activate the virtual environment (Windows)
venv\Scripts\activate

# (Optional: On macOS/Linux, use: source venv/bin/activate)

# Install requirements
pip install -r requirements.txt
